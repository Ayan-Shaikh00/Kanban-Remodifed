A modern, responsive Kanban task management application built with HTML, CSS, and vanilla JavaScript. Features drag-and-drop task organization, task creation and deletion, real-time task counters, and persistent storage using LocalStorage. Designed with clean, reusable code, responsive layouts, and a focus on maintainability, accessibility, and secure DOM manipulation.

**Key Features**
- 📋 Organize tasks into To-Do, In Progress, and Done columns.
- 🖱️ Drag and drop tasks between columns.
- ➕ Create and delete tasks dynamically.
- 💾 Persist tasks using browser LocalStorage.
- 📊 Automatically update task counts.
- 📱 Responsive design for desktop and mobile.
- 🎨 Modern dark UI with reusable CSS variables.
- 🛡️ Safer DOM manipulation using `textContent`.
- 🧩 Modular JavaScript functions for maintainability.

**Tech Stack:** HTML5 · CSS3 · JavaScript · LocalStorage API

**Project Goal:** Build a maintainable, production-oriented frontend project while applying clean code principles, responsive design, and practical JavaScript development patterns.
